台股條件篩選

連線設定

只需設定一次，資料只存在這支手機的瀏覽器裡。

  1. GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token。
  2. Repository access 選 Only select repositories，只勾你的 twStock。
  3. Permissions：Actions → Read and write、Contents → Read-only。
  4. 把產生的 token 貼在下面。

要做什麼

個股區間分析（列出這檔股票一年內的每個盤整區間）

這是事後視角：用整年資料回頭找出每個區間。收盤價超出壓力（支撐）達「突破幅度」，區間就結束，接著重新找下一個；只超出一點就是區間變大。不確定怎麼填就用預設值。

批次回測（把每一組篩選各回測一次，做成排行榜）

每一組都會算全期、前半段、後半段，各自對照同期市場平均。兩段都贏過才標「穩」。下面可以選要跑哪幾組，預設全部。執行時間比單一回測久（約 5～15 分鐘），請保持這個頁面開著。

今日名單（同時符合越多組篩選的股票排越前面）

每一組篩選各跑一次，再合併成一張股票表。選的組方向要一致才有意義（例如都偏多）。這是縮小範圍的工具，不是買進建議。

條件（一層一層往下篩）

第 2 層只會在第 1 層的結果裡找。同一層裡放多個條件時，可選「且」（全部符合）或「或」（符合任一個）。
